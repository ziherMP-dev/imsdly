
Imsdly - PyQt File Transfer Application PRD

1. Core Functionality:
1.1. Transfer media files (photos and videos in various formats) from external storage devices to computer
1.2. Automatic device detection when connected (all supported storage devices)
1.3. Multiple storage devices processed simultaneously
1.4. Option to remove files from source devices after successful import

2. File Organization:
2.1. User choice between:
2.1.1. Organizing files into folders by date
2.1.2. Custom folder structure based on metadata
2.2. Batch file renaming (base filename + sequential numbering)
2.3. Advanced settings (Custom rename pattern, Sequence number options)

3. Transfer Features:
3.1. Transfer verification to prevent corruption
3.2. Transfer functionality with resume capability

4. User Interface:
4.1. Different viewing modes (displaying files as List, Icons, Thumbnails)
4.2. Configurable default destination folders
4.3. Device selection panel for choosing among multiple connected storage devices

5. Filtering Options:
5.1. Filter by date taken
5.2. Filter by file size
5.3. Filter by file type/format
5.4. Filter by filename
5.5. Filter by storage device type

6. Device Support:
6.1. SD Card Family:
6.2. microSD Card Family:
6.3  USB flash drives
6.4. External hard drives
6.5. External SSDs

7. Not Included (for now):
7.1. Licensing system (to be handled later)
